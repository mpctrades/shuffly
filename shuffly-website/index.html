03 — What's different

Built to be the boring, reliable option

No storefront code, no theme edits, and every run can be undone.

Compatibility

Rewrites the real, stored sort order — not the rendered page. Works with any theme, and with both custom and automated collections, as long as the collection is set to manual sort (which Shopify allows for either).

Speed

Nothing runs on your storefront. No script tag, no theme edit — the work happens entirely on Shopify's servers before a shopper ever loads the page.

Control

Pin your first N products so hero items never move. Exclude anything tagged gift-card, preorder, or bundle — or your own custom tags.

Freshness

Sold-out products get pushed to the end automatically. Products created in the last 14 days get boosted toward the top instead of starting buried on page twelve.

Why it's worth paying for

Fairness, measured

Insights shows exactly how evenly turns are shared across a collection — not just that it happened, but who's waited longest and how fast a sold-out item actually got demoted.

Honesty

Off by default on every collection you haven't explicitly turned on. Every run is logged, visible, and can be undone.
